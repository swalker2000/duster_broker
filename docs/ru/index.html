📖 О проекте

Duster Broker — это промежуточный слой над MQTT, с гарантиями доставки, отслеживанием статуса и ограничением скорости для Интернета вещей. Поддерживает ESP32, REST API, Docker. Котлин + Spring Boot.

Стек: Kotlin + Spring Boot, PostgreSQL, Docker.

✨ Возможности

  • Гарантии доставки: ONLY_LAST (только последнее), RECEIPT_CONFIRMATION (все сообщения), NO (без гарантии).
  • Контроль потока: ограничение интервала отправки, чтобы не переполнить буфер устройства.
  • Отслеживание статусов: NOT_DELIVERED, DELIVERED, COMPLETED, COMPLETED_WITH_ERROR.
  • Двойной интерфейс: MQTT + REST API (документация через Swagger).
  • Админ-панель: http://localhost:8080 (логин/пароль: admin/admin).

🔄 Принцип работы

  1. Продюсер отправляет JSON ProducerMessageInDto в топик producer/request/{deviceId}.
  2. Создаётся ConsumerMessageOutDto с уникальным ID.
  3. Сообщение отправляется потребителю в топик consumer/request/{deviceId}.
  4. Если гарантия не NO, ожидается ответ ConsumerMessageInDto в consumer/response/{deviceId}.
  5. При таймауте — повторная отправка.
  6. Продюсер получает обновления статуса в producer/response/{producerDeviceId}.

⚡ Быстрый старт

Docker Compose

git clone https://github.com/swalker2000/duster_broker.git
cd duster_broker
# Создайте .env файл с:
# MQTT_BROKER_USERNAME=your_user
# MQTT_BROKER_PASSWORD=your_pass
# WEBSOCKET_PORT=9443
# MQTT_PORT=8883
docker compose up -d

Сервисы: MQTT-брокер, PostgreSQL, сам Duster.

JAR-файл

gradle build
cp build/libs/duster-*.jar .
cp src/main/resources/application.yaml .
# Настройте application.yaml
java -jar duster-0.0.1-SNAPSHOT.jar

💡 Пример для ESP32

Пример потребителя на ESP32: duster_esp32_example.

#define SSID "MY_SSID"
#define WIFI_PASS "MY_WIFI_PASS"
#define URL "MQTT_URL"
#define PORT 8883
#define MQTT_USERNAME "username"
#define MQTT_PASS "password"

Устройство мигает светодиодом по командам из топика consumer/request/device123.

🔗 Интеграция с OpenRemote

OpenRemote не поддерживает самоподписанные сертификаты, поэтому переключите MQTT на незашифрованный режим.

Создайте MQTT Agent, настройте атрибуты устройства и публикуйте ProducerMessageInDto в топик producer/request/{deviceId}.
