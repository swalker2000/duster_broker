🚀 Duster Broker

MQTT-based message broker with delivery guarantees, status tracking, and rate limiting for IoT

About Features Workflow Quick Start ESP32 Example OpenRemote

📖 About

Duster Broker - is a middle layer on top of MQTT, with delivery guarantees, status tracking, and rate limiting for the Internet of Things. Supports ESP32, REST API, Docker.

Stack: Kotlin + Spring Boot, PostgreSQL, Docker.

✨ Features

  • Delivery guarantees: ONLY_LAST, RECEIPT_CONFIRMATION, NO.
  • Rate limiting: prevents buffer overflow on constrained devices.
  • Status tracking: NOT_DELIVERED, DELIVERED, COMPLETED, COMPLETED_WITH_ERROR.
  • Dual interface: MQTT + REST API (Swagger docs at /swagger-ui.html).
  • Admin panel: http://localhost:8080 (login/password: admin/admin).

🔄 Workflow

  1. Producer sends ProducerMessageInDto to producer/request/{deviceId}.
  2. A ConsumerMessageOutDto with a unique ID is created.
  3. The message is published to consumer/request/{deviceId}.
  4. If guarantee is not NO, the service waits for ConsumerMessageInDto on consumer/response/{deviceId}.
  5. On timeout, the message is resent.
  6. Status updates are sent to the producer on producer/response/{producerDeviceId}.

⚡ Quick Start

Docker Compose

git clone https://github.com/swalker2000/duster_broker.git
cd duster_broker
# Create .env file with:
# MQTT_BROKER_USERNAME=your_user
# MQTT_BROKER_PASSWORD=your_pass
# WEBSOCKET_PORT=9443
# MQTT_PORT=8883
docker compose up -d

JAR File

gradle build
cp build/libs/duster-*.jar .
cp src/main/resources/application.yaml .
# Edit application.yaml
java -jar duster-0.0.1-SNAPSHOT.jar

💡 ESP32 Example

Consumer example: duster_esp32_example.

#define SSID "MY_SSID"
#define WIFI_PASS "MY_WIFI_PASS"
#define URL "MQTT_URL"
#define PORT 8883
#define MQTT_USERNAME "username"
#define MQTT_PASS "password"

The ESP32 blinks an LED on commands from consumer/request/device123.

🔗 OpenRemote Integration

OpenRemote requires insecure MQTT (no TLS). Create an MQTT Agent, configure device attributes, and publish ProducerMessageInDto to producer/request/{deviceId}.
