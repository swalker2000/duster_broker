Отправка сообщения на устройство

Устройства задаются на странице «Клиенты и устройства» (клиент с ролью DEVISE). Статус после отправки: GET /producer/getMessageStatus/{id}

Отправленные сообщения

GET /admin/api/messages — последние записи, новые сверху. Клик по строке подставляет устройство, гарантию, команду и данные в форму отправки выше.
